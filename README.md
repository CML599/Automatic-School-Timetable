This project consists of three main parts; the HTML documnet(titled "timetable.html"), CSS file ("style.css") and Javascript file ("script.js").

The HTML is meant to provide the basic structure of the system.

The CSS file mainly provides aesthetic details for the system's interface so as to make it less barebones in the eyes of the user while still maintaining functionality.

The Javascript file is where large parts of the functionality come from, such as the variables and constants needed to make the timetable more dynamic and flexible.
